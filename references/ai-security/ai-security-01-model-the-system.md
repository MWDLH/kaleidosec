## Model The System

Map user roles, application boundaries, models and providers, system prompts, developer instructions, retrieval sources (vector stores, knowledge bases, APIs), memory/context storage, file/URL ingestion, plugin or tool schemas, agent orchestration (single agent, multi-agent, tool-calling loop), human approval steps, output consumers (APIs, email, code executors, databases), data retention, evaluation controls, and supply-chain components (models, adapters, datasets, plugins).

**The model is one component, not the whole system.** Most material paths cross application authorization, retrieval, tool permissions, data isolation, or downstream automation — just like traditional web apps. AI adds new attack surface but does not replace existing ones.
