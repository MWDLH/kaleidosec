## Domain Transitions

- **→ supply-chain**: For CI/CD pipeline identities, build service accounts, and container registry access
- **→ Web/API**: For exposed services (S3 websites, API Gateway, CloudFront, App Service, Cloud Run)
- **→ internal/AD**: For hybrid identity (Azure AD Connect, AWS Managed AD, federation)
- **→ AI**: For hosted model endpoints (SageMaker, Bedrock, Vertex AI)
- **→ evasion**: When GuardDuty/CloudTrail detection is active (avoid triggering specific APIs)
