## Return To Parent Path

Return:
1. **Effective identity**: Principal, domain/tenant, groups/roles, scope of access
2. **Verified scope**: Which assets this identity was confirmed to reach
3. **Limitations**: What the identity CANNOT do (also important intelligence)
4. **New network position**: Reachable subnets, services, trusts discovered from this position
5. **Credential quality**: Crackable? Reusable across targets? Time-bounded?
6. **Affected parent paths**: Which parked paths can now be reactivated
