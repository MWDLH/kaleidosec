# Internal Network, Host, And Identity Operations: Recollect When

> Apply [../module-continuity.md](../module-continuity.md). Inherit the engagement, parent path, current capability, evidence, authorization profile, and module stack. Do not initialize a separate workflow. Checkpoint material results and return them to the parent path before leaving this card.

## Recollect When

Recollect after:
- Gaining a new identity (user, machine account, service account, gMSA)
- Obtaining new privilege (local admin, domain admin, specific ACL right, replication right)
- Moving to a new host (especially domain controller, CA server, Exchange, SCCM, or file server)
- Entering a new network segment or VLAN
- Discovering a trust relationship
- Finding credential material (hash, ticket, key, password, token)
- Detecting a defensive control that limits technique selection

## Card Exit

Classify the result, update evidence and attempted methods, record capability or risk changes, identify affected paths, and apply the return contract in [../module-continuity.md](../module-continuity.md).
