# Mini-Program Operations: Recollect When

> Apply [../module-continuity.md](../module-continuity.md). Inherit the engagement, parent path, current capability, evidence, authorization profile, and module stack. Do not initialize a separate workflow. Checkpoint material results and return them to the parent path before leaving this card.

## Recollect When

Recollect after:
- Identifying a new backend environment (subpackage may point to different API host)
- Finding a privileged function call (admin operations in cloud functions)
- Discovering another mini-program sharing the same backend (code reuse across apps → potential cross-app access)
- Extracting tokens from local storage (replay against backend from outside the mini-program)
- Finding AppSecret in the unpacked code (game-changing)

## Card Exit

Classify the result, update evidence and attempted methods, record capability or risk changes, identify affected paths, and apply the return contract in [../module-continuity.md](../module-continuity.md).
