# CI/CD And Software Supply-Chain Operations: Build The Delivery Graph

> Apply [../module-continuity.md](../module-continuity.md). Inherit the engagement, parent path, current capability, evidence, authorization profile, and module stack. Do not initialize a separate workflow. Checkpoint material results and return them to the parent path before leaving this card.

## Build The Delivery Graph

Map source repositories (GitHub, GitLab, Bitbucket, Azure DevOps), contributors and service identities, branch protection rules, code review requirements, CI systems (GitHub Actions, GitLab CI, Jenkins, CircleCI, Azure Pipelines), runners (self-hosted, GitHub-hosted, ephemeral), build definitions (workflows, Jenkinsfiles, .gitlab-ci.yml, azure-pipelines.yml), secret stores (GitHub Secrets, HashiCorp Vault, Azure Key Vault, AWS Secrets Manager), package registries (npm, PyPI, Maven, NuGet, Docker Hub, ECR, ACR, GCR, Artifactory), artifact signing, deployment targets, update channels, infrastructure-as-code (Terraform, CloudFormation, Pulumi, Ansible), dependency sources, and environment promotion paths.

The supply chain is the **highest-leverage attack surface** in modern environments. One compromised workflow can deploy to production, bypassing every network control and application defense.
