# CI/CD And Software Supply-Chain Operations: Recollect When

> Apply [../module-continuity.md](../module-continuity.md). Inherit the engagement, parent path, current capability, evidence, authorization profile, and module stack. Do not initialize a separate workflow. Checkpoint material results and return them to the parent path before leaving this card.

## Recollect When

Recollect after:
- Gaining write access to a repository (can you modify workflows?)
- Discovering a CI/CD configuration (workflows, pipelines, Jenkinsfiles)
- Finding package registry credentials (can you publish packages?)
- Accessing a container registry (can you pull, push, or modify images?)
- Obtaining CI/CD runner access (self-hosted or ephemeral)
- Finding a `.tfstate` file or Terraform backend
- Discovering an OIDC trust configuration (can other repos/branches assume the role?)

## Card Exit

Classify the result, update evidence and attempted methods, record capability or risk changes, identify affected paths, and apply the return contract in [../module-continuity.md](../module-continuity.md).
